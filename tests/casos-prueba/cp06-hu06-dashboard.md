# CP-06 — HU-06 Dashboard de información

**Objetivo:** Verificar que un usuario autorizado pueda acceder al dashboard y visualizar indicadores.

**Historia asociada:** HU-06 – Dashboard de información

**Precondiciones:**
- Usuario autenticado.
- Permisos para acceder al dashboard.
- Datos disponibles en el sistema.
- Dashboard implementado.

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Acceder al módulo Dashboard | Se muestra el panel de indicadores. |
| 2 | Verificar carga de gráficos | Los gráficos se cargan correctamente. |
| 3 | Verificar actualización de datos | Los indicadores muestran datos actuales. |
| 4 | Aplicar filtro temporal | El dashboard recalcula según el rango. |
| 5 | Exportar vista (si aplica) | El sistema genera el reporte o imagen. |

**Resultado esperado final:** El usuario visualiza correctamente indicadores e información del dashboard.

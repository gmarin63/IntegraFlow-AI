# CP-01 — HU-01 Inicio de sesión

**Objetivo:** Verificar que un usuario registrado pueda ingresar a IntegraFlow AI con credenciales válidas.

**Historia asociada:** HU-01 – Inicio de sesión

**Precondiciones:**
- Usuario registrado y activo.
- Plataforma disponible.
- Credenciales válidas.

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Abrir la plataforma | Se muestra la pantalla de inicio de sesión. |
| 2 | Ingresar correo válido | El sistema acepta el correo. |
| 3 | Ingresar contraseña válida | El sistema acepta la contraseña. |
| 4 | Seleccionar “Iniciar sesión” | El sistema valida las credenciales. |
| 5 | Esperar respuesta | El usuario accede según su rol y permisos. |

**Resultado esperado final:** El usuario ingresa correctamente a la plataforma.

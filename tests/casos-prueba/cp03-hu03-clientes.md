# CP-03 — HU-03 Gestión de clientes

**Objetivo:** Verificar que un usuario autorizado pueda registrar y consultar clientes.

**Historia asociada:** HU-03 – Gestión de clientes

**Precondiciones:**
- Usuario autenticado.
- Permisos para acceder al CRM.
- Módulo CRM disponible.

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Acceder al CRM | Se muestra el módulo de clientes. |
| 2 | Seleccionar “Nuevo cliente” | Se muestra el formulario. |
| 3 | Ingresar datos válidos | El sistema recibe y valida los datos. |
| 4 | Guardar | El cliente queda almacenado. |
| 5 | Consultar clientes | El registro aparece en la lista. |

**Resultado esperado final:** El usuario puede administrar correctamente la información del cliente.

# CP-08 — HU-08 Asistencia mediante Inteligencia Artificial

**Objetivo:** Verificar que un usuario autorizado pueda acceder y utilizar asistencia inteligente.

**Historia asociada:** HU-08 – Asistencia mediante Inteligencia Artificial

**Precondiciones:**
- Usuario autenticado.
- Permisos para acceder a la asistencia IA.
- Motor IA disponible.
- Conexión activa al servicio.

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Acceder a la interfaz de asistencia | Se muestra el chat o interfaz de IA. |
| 2 | Formular una pregunta o solicitud | El sistema recibe y procesa la entrada. |
| 3 | Esperar respuesta de IA | El sistema genera una respuesta relevante. |
| 4 | Evaluar respuesta (satisfacción) | El sistema registra la retroalimentación. |
| 5 | Solicitar información adicional | La IA mantiene contexto de la conversación. |

**Resultado esperado final:** El usuario interactúa correctamente con la asistencia inteligente.

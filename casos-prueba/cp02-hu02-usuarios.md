# CP-02 — HU-02 Gestión de usuarios

**Objetivo:** Verificar que un administrador pueda consultar y gestionar usuarios.

**Historia asociada:** HU-02 – Gestión de usuarios

**Precondiciones:**
- Administrador autenticado.
- Permisos de administración.
- Módulo de usuarios disponible.

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | Acceder al módulo Usuarios | Se muestra la lista de usuarios. |
| 2 | Seleccionar “Nuevo usuario” | Se muestra el formulario de registro. |
| 3 | Ingresar datos válidos | El sistema valida la información. |
| 4 | Guardar | El usuario queda registrado. |
| 5 | Consultar la lista | El nuevo registro aparece. |

**Resultado esperado final:** El administrador puede gestionar usuarios correctamente.

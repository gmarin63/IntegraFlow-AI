# GA1-220501092-AA5-EV01

## Determinación de las especificaciones funcionales del software y metodología a utilizar

### Proyecto
**IntegraFlow AI**

## 1. Introducción

El desarrollo de IntegraFlow AI requiere organizar, documentar, priorizar y realizar seguimiento a los requerimientos y actividades del software. Para esta etapa se selecciona GitHub Projects como herramienta de apoyo para la gestión del proyecto y de las historias de usuario.

IntegraFlow AI es una plataforma web orientada a la automatización e integración de procesos empresariales mediante Inteligencia Artificial. La propuesta contempla los módulos CRM, RRHH, Contabilidad y Documentos, junto con un motor de IA y automatización y futuras integraciones con Gmail, DIAN API y WhatsApp.

## 2. Objetivo general

Determinar las especificaciones funcionales iniciales de IntegraFlow AI y establecer una herramienta tecnológica para gestionar, organizar, priorizar y realizar seguimiento a sus requerimientos y actividades.

## 3. Herramienta seleccionada

**GitHub Projects** es la herramienta seleccionada para gestionar el trabajo del proyecto. Se complementa con GitHub Issues para registrar las historias de usuario y permite organizarlas mediante un tablero de trabajo.

Repositorio: https://github.com/gmarin63/IntegraFlow-AI

## 4. Justificación

GitHub Projects permite centralizar la gestión del trabajo junto con el repositorio del proyecto. Para IntegraFlow AI facilita la organización de historias de usuario, priorización, seguimiento de estados y trazabilidad entre requisitos y actividades de desarrollo.

## 5. Flujo de trabajo

El flujo definido para el proyecto es:

**Backlog → Por hacer → En progreso → En pruebas → Completado**

- **Backlog:** funcionalidades identificadas pendientes de planificación.
- **Por hacer:** actividades definidas y listas para iniciar.
- **En progreso:** actividades actualmente en desarrollo.
- **En pruebas:** funcionalidades desarrolladas que requieren validación.
- **Completado:** funcionalidades verificadas y finalizadas.

## 8. Relación con el levantamiento de información

La definición de las funcionalidades se relaciona con la encuesta aplicada durante el levantamiento de requisitos. La muestra disponible fue de 19 personas.

Resultados relevantes:

| Hallazgo | Resultado |
|---|---:|
| Consideran que los procesos actuales podrían optimizarse mediante automatización | 16 de 19 (84,2 %) |
| Consideran la automatización de tareas como funcionalidad más importante | 12 de 19 (63,2 %) |
| Principal inconveniente: errores manuales | 8 de 19 (42,1 %) |
| Ingresan información en diferentes aplicaciones frecuentemente o siempre | 8 de 19 (42,1 %) |
| Almacenan documentación en la nube | 9 de 19 (47,4 %) |

Estos resultados respaldan la orientación del proyecto hacia la automatización, integración y centralización de información.

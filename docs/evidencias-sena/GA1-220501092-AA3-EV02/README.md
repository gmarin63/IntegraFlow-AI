# GA1-220501092-AA3-EV02 — Formulación del proyecto de software

## Proyecto: IntegraFlow AI

### Introducción

IntegraFlow AI se plantea como una plataforma web para automatizar e integrar procesos empresariales mediante Inteligencia Artificial. La propuesta surge del análisis de necesidades relacionadas con tareas repetitivas, errores manuales, duplicidad de información y falta de integración entre herramientas.

### Herramienta de captura de requisitos

Se utiliza el enfoque de **historias de usuario** para formular las necesidades funcionales de manera comprensible para los usuarios y el equipo de desarrollo.

### Historias iniciales

- **HU-01:** Inicio de sesión — Usuarios y Seguridad — 3 puntos — Alta.
- **HU-02:** Gestión de usuarios — Usuarios y Seguridad — 5 puntos — Alta.
- **HU-03:** Gestión de clientes — CRM — 5 puntos — Alta.
- **HU-04:** Gestión documental — Documentos — 5 puntos — Alta.
- **HU-05:** Automatización de procesos — IA y Automatización — 8 puntos — Alta.
- **HU-06:** Dashboard de información — Dashboard y Reportes — 5 puntos — Alta.
- **HU-07:** Generación de reportes — Dashboard y Reportes — 5 puntos — Media.
- **HU-08:** Asistencia mediante Inteligencia Artificial — IA y Automatización — 8 puntos — Alta.

### Alcance

La propuesta contempla los módulos CRM, RRHH, Contabilidad y Documentos, integrados con un motor de IA y automatización. Se consideran además integraciones previstas con Gmail, DIAN API y WhatsApp.

### Resultado

La formulación permitió transformar las necesidades identificadas en historias de usuario priorizadas que sirven como base para la especificación y gestión posterior del proyecto.

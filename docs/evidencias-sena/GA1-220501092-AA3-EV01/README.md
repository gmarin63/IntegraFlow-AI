# GA1-220501092-AA3-EV01 — Diseño del instrumento de recolección de información

## Proyecto: IntegraFlow AI

### Introducción

Esta evidencia documenta el diseño del instrumento utilizado para recopilar información orientada al levantamiento de requisitos de IntegraFlow AI, una plataforma web propuesta para automatizar e integrar procesos empresariales mediante Inteligencia Artificial.

### Técnica seleccionada

Se seleccionó la **encuesta** como técnica de recolección de información, por permitir obtener información estructurada de diferentes usuarios potenciales y facilitar posteriormente el análisis cuantitativo de las respuestas.

### Objetivo

Identificar necesidades, procesos repetitivos, herramientas actuales, dificultades y oportunidades de automatización que permitan definir los requisitos iniciales de IntegraFlow AI.

### Alcance

El instrumento se orienta a personas que desarrollan actividades relacionadas con administración, contabilidad, recursos humanos, área comercial, compras y gerencia.

### Estructura del instrumento

Las preguntas diseñadas abordaron, entre otros aspectos:

1. Área en la que desempeña sus funciones.
2. Software utilizado actualmente.
3. Proceso realizado con mayor frecuencia.
4. Tiempo dedicado diariamente a tareas repetitivas.
5. Frecuencia de ingreso de la misma información en diferentes aplicaciones.
6. Principal inconveniente del proceso.
7. Medio por el que recibe información de clientes o proveedores.
8. Forma de almacenamiento de documentación.
9. Frecuencia de generación de reportes.
10. Percepción sobre la automatización de procesos.
11. Funcionalidad considerada más importante en un nuevo sistema.
12. Importancia de integrar varias áreas en una sola plataforma.

### Relación con el proyecto

Las preguntas fueron diseñadas para identificar necesidades directamente relacionadas con la propuesta de IntegraFlow AI: automatización de tareas, integración de procesos, gestión documental, generación de información y centralización de operaciones.

### Resultado

El instrumento sirvió como base para la aplicación de la encuesta y para las evidencias posteriores de formulación y análisis de requisitos.

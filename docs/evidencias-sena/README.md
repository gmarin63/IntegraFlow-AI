## Criterio de organización

Las evidencias se incorporan al repositorio como documentación del proceso del proyecto. Los documentos académicos finales pueden contener portada, formato institucional y capturas requeridas para la entrega al SENA; este repositorio conserva principalmente la información técnica y de trazabilidad del proyecto.

## Proyecto

**IntegraFlow AI** es una plataforma web propuesta para automatizar e integrar procesos empresariales mediante Inteligencia Artificial, con módulos de CRM, RRHH, Contabilidad y Documentos, un motor de IA y automatización e integraciones previstas con Gmail, DIAN API y WhatsApp.

## Nota sobre resultados de encuesta

La encuesta utilizada para el levantamiento de requisitos alcanzó una muestra de 19 respuestas. Los resultados documentados en las evidencias se mantienen como fuente del análisis de requisitos y se relacionan con las historias de usuario y funcionalidades del proyecto.

## Criterio de organización

Las evidencias se incorporan al repositorio cuando aportan información técnica reutilizable al proyecto. Los documentos académicos finales pueden contener portada, formato institucional, videos o capturas requeridas para Zajuna; estos elementos no se duplican necesariamente en GitHub.

Se priorizan formatos mantenibles como **Markdown, SVG y código fuente**, con el fin de que la documentación pueda evolucionar junto con el software.

## Proyecto

**IntegraFlow AI** es una plataforma web propuesta para automatizar e integrar procesos empresariales, con módulos de CRM, Recursos Humanos, Contabilidad y Gestión Documental, servicios de automatización e integraciones externas previstas.

## Nota sobre resultados de encuesta

La encuesta utilizada para el levantamiento de requisitos alcanzó una muestra de 19 respuestas. Los resultados documentados en las evidencias se mantienen como fuente del análisis de requisitos y se relacionan con las historias de usuario y funcionalidades del proyecto.

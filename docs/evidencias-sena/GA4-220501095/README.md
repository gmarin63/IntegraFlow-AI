## Decisión arquitectónica consolidada

IntegraFlow AI se plantea como una aplicación web modular con separación de responsabilidades entre interfaz, lógica de negocio, persistencia e integraciones. La solución contempla módulos de **CRM, Recursos Humanos, Contabilidad y Gestión Documental**, apoyados por servicios de automatización e integraciones externas.

Las decisiones de GA4 sirven como línea base para la construcción de prototipos, interfaces, navegación y maquetación que se desarrollarán en GA5.

## Alcance del repositorio

Los trabajos transversales de comunicación e inglés se entregan en los medios académicos correspondientes. En GitHub se conserva principalmente aquello que aporta al análisis, diseño, arquitectura, implementación y trazabilidad de IntegraFlow AI.
